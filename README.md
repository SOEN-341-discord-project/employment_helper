# CareerConnect

## Project Description

CareerConnect is a website that helps people search for jobs and keep track of their job application.

## Problem

When applying for many jobs, it can be difficult to remember where you applied and what stage each application is at.

## Proposed Solution 

Our website will allow users to keep their job search organized in one place. Users will be able to create an account, manage their profile, upload their resume, search for jobs and keep track of their applications.

## Setup Instructions 

1. Clone the GitHub repository.
2. Open the project in Visual Studio Code.
3. Install the required dependencies using "npm install"
4. Code the login-page front and back-end
5. Code the backend of the file upload mechanism
6. Run the backend server using "node server/index.js"
7. Configure a Supabase database to hold seperately the uploaded resumes and the signed up users' credentials.

## Proposed Features

- User registration, authentication, and profile management. 
- Resume upload andmanagement. 
- Job posting management for recruiters. 
- Job search and filtering capabilities. 
- Job application submission. 
- Application status tracking (Applied, Interview, Offered, Rejected). 
- Application history dashboard. 
- Notifications and reminders for application deadlines. 
- Saved jobs and favourites. 
- AI-assisted resume feedback 
- AI-assisted job description summaries

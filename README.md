# CareerConnect

## Project Description

CareerConnect is a website that helps people search for jobs and keep track of their job application.

## Problem

When applying for many jobs, it can be difficult to remember where you applied and what stage each application is at.

## Proposed Solution 

Our website will allow users to keep their job search organized in one place. Users will be able to create an account, manage their profile, upload their resume, search for jobs and keep track of their applications.
